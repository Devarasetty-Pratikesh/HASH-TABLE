# HashTableFundamentalsApp

## Use Case 3 - DNS Cache with TTL

### Objective
To implement a DNS cache using HashMap with expiration logic.

### Concepts Used
- HashMap
- TTL
- Cache hit/miss
- Time-based expiry

### Flow
1. Store domain and IP mapping
2. Save expiry time
3. Check if entry exists and is valid
4. Return HIT or MISS
